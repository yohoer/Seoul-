# Seoul♡ Seoul Trip App

React + Vite travel app based on the uploaded App component.

## Local test
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deploy to Vercel
Import this project/repository into Vercel. Build command: `npm run build`; output directory: `dist`.

## Deploy to Netlify
Build command: `npm run build`; publish directory: `dist`.
